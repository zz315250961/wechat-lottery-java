# 校园抽奖系统若依重构实施计划

## 目标

在不迁移旧业务数据的前提下，以若依 Spring Boot 2 为后端底座，使用 Java 8、Spring Boot 2.5.15、MyBatis-Plus、MySQL 8、Redis 和 Vue 3 + Vite + JavaScript，完整复刻现有用户端、商户端、管理端功能与界面。

## 总体结构

- `backend/`：若依 Spring Boot 2 多模块工程，保留权限、安全、日志、Redis、异常处理等基础能力。
- `frontend/`：Vue 3 单仓三端应用，路由分别为 `/`、`/admin`、`/merchant`。
- `sql/`：若依系统表、抽奖业务表及初始化菜单。
- `docs/`：架构、接口、数据库、运行部署和验收说明。

## 实施阶段

### 1. 工程基线

- 固定 Java 8、Spring Boot 2.5.15 和兼容依赖版本。
- 引入 MyBatis-Plus、MySQL 8 驱动、Redis。
- 建立 Vue 3 + Vite + JavaScript 工程和三端路由。
- 配置开发环境样例，不写入真实密钥。

### 2. 领域与数据

- 活动、活动规则、商户、奖品、用户、每日次数、助力、抽奖、奖券、定向中奖。
- 抽奖事务内完成幂等校验、次数扣减、库存扣减、中奖记录和奖券创建。
- 奖券保存奖品、图片、商户地址和使用规则快照。
- Redis 承担登录会话、限流、幂等短锁和微信票据缓存；MySQL 保持最终真实数据。

### 3. 后端接口

- 用户：测试登录、微信授权预留、个人状态、签到、助力、抽奖、奖券。
- 商户：登录、奖券查询、扫码/手输核销、核销记录。
- 管理：活动、公告规则、主题、奖池、商户、用户、记录、隐藏定向中奖。
- 上传：图片类型、大小、文件签名和访问路径校验。

### 4. 三端界面复刻

- 用户端：移动端转盘、滚动公告、签到、好友助力、奖券详情和分享引导。
- 商户端：移动端全屏扫码，识别后返回核销页并填充券码。
- 管理端：复刻现有布局、表格、搜索、统一居中弹窗、未保存状态和实时数据刷新。
- 所有关键操作提供成功、失败、确认和空状态反馈。

### 5. 测试与交付

- 服务层单元测试覆盖抽奖、库存、个人上限、助力、幂等和核销。
- 接口测试覆盖三类身份权限和主要错误分支。
- 前端构建、关键组件测试及手机视口检查。
- 输出数据库脚本、配置说明、运行命令和迁移/部署手册。

## 验收原则

- 三端路由与旧系统一致，核心业务闭环可独立运行。
- 后台展示的库存、中奖、奖券与核销统计来自同一真实数据源。
- 刷新后登录有效；管理员、用户、商户会话互不覆盖。
- 不在仓库中提交真实 AppSecret、数据库密码或线上会话数据。
